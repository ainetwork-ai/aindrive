# A2UI — the UI every result carries

[A2UI](https://a2ui.org) is a declarative UI format: the agent sends JSON, your
app draws it with its own native components. aindrive describes the result of
**every** skill as an A2UI surface and sends the same surface over MCP, A2A and
AG-UI — one UI definition, three transports.

| | |
|---|---|
| Version | **v0.9** (messages carry `"version": "v0.9"`) |
| Catalog | basic catalog `https://a2ui.org/specification/v0_9/catalogs/basic/catalog.json` — no custom components to install |
| MIME type | `application/a2ui+json` |
| Renderers | `@a2ui/lit`, `@a2ui/react`, `@a2ui/angular`, Flutter, CopilotKit — or aindrive's tiny dependency-free renderer (`shared/a2ui/renderer.js`) |

## Surfaces

| Skill | Surface | What it shows |
|---|---|---|
| `list_drives` | `aindrive-drives-*` | the user's drives; each opens with `aindrive.open_drive` |
| `list_files` | `aindrive-browser-*` | folder title, ⬆ Up, search box, one row per entry (🔒 = paid, not bought) |
| `search` | `aindrive-search-*` | matches with full paths, same toolbar |
| `read_file` | `aindrive-preview-*` | text / markdown / code, or the image itself; ⬅ Back |
| `write_file`, `delete_path`, `stat` | `aindrive-result-*` / `aindrive-stat-*` | a card with the outcome and 📁 Open folder |
| any error | `aindrive-error-*` | a card with `[code] message` |

Each surface is three messages — `createSurface`, `updateComponents` (a flat
component list with a `root`), and `updateDataModel` (path `/`). List rows are
a template over `/items`:

```json
{ "label": "📄 report.pdf", "meta": "1.2 MB", "path": "docs/report.pdf",
  "is_dir": false, "drive_id": "…" }
```

## Actions (renderer → aindrive)

Buttons fire A2UI `action` events. Send the resolved action back through the
transport you use; aindrive answers with the next surface.

| `action.name` | `context` | Runs |
|---|---|---|
| `aindrive.open` | `drive_id`, `path`, `is_dir` | `list_files` (folder) or `read_file` (file) |
| `aindrive.search` | `drive_id`, `query`, `path` | `search` (empty query → `list_files`) |
| `aindrive.open_drive` | `drive_id` | `list_files` at the drive root |

| Transport | Send the action as |
|---|---|
| MCP | `tools/call` → `a2ui_action` with `{ "action": … }` |
| A2A | a DataPart `{ "version": "v0.9", "action": … }` |
| AG-UI | `forwardedProps.a2uiAction = { userAction: … }` |

## Rendering it yourself

```ts
import { createA2uiRenderer } from "<aindrive>/shared/a2ui/renderer.js"; // or @a2ui/lit / @a2ui/react

const view = createA2uiRenderer(document.getElementById("app"), {
  onAction: async (action) => view.replace(await sendToAindrive(action)),
});
view.replace(messages);   // the application/a2ui+json payload
```
